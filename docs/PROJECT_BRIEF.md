# Alpha Gold Project Brief

## Summary

Alpha Gold is a professional geological modelling case study designed to show how drilling data can be organized, validated, interpreted, and transformed into portfolio-ready geological outputs.

The case study uses a sanitized public-facing name and can be supported by synthetic or anonymized datasets. It should not include client names, real coordinates, confidential assay values, original drilling contracts, internal commercial information, or restricted operational data.

## Intended Audience

- Mining and exploration companies.
- Geological and geotechnical consultancies.
- Academic evaluators.
- Technical recruiters.
- Geodata, modelling, and mining software teams.

## Technical Themes

- Drillhole database structure.
- Collar, survey, lithology, and optional assay QA/QC.
- Geological interpretation under uncertainty.
- 3D modelling workflow documentation.
- Reproducible project organization.
- Portfolio-oriented communication.

## Case Study Boundaries

This repository should demonstrate method and judgement, not disclose proprietary data. The public version may include:

- Synthetic drilling tables.
- Sanitized workflows.
- Generic geological interpretations.
- Non-sensitive screenshots.
- Educational notes on modelling decisions.

The public version should not include:

- Real client or mine names without permission.
- Real coordinates.
- Original drilling logs.
- Confidential assays.
- Commercial rates, contracts, or operational constraints.
- Internal company documents.
