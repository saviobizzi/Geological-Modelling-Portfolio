# Alpha Gold Geological Modelling Portfolio

This repository presents **Alpha Gold**, a sanitized geological modelling case study created for a professional portfolio.

The objective is to demonstrate a complete and auditable modelling workflow: data organization, QA/QC, geological interpretation, Leapfrog/QGIS-ready structure, and clear deliverables. The repository is intentionally designed to avoid exposing confidential coordinates, client names, original drilling databases, or operationally sensitive information.

## Portfolio Goals

- Show a practical geological modelling workflow from drilling data to interpreted outputs.
- Document QA/QC decisions in a way that can be reviewed by technical and non-technical audiences.
- Keep raw, processed, interpreted, and deliverable materials separated.
- Support future public and private versions of the same portfolio.
- Build a professional repository that can be used in job applications, consulting discussions, academic conversations, and geodata/tech positioning.

## Repository Structure

| Folder | Purpose |
| --- | --- |
| `data/raw/` | Placeholder for original confidential files. This folder should remain empty in the public repository. |
| `data/synthetic/` | Synthetic example tables for portfolio demonstrations. |
| `data/processed/` | Cleaned and validated datasets prepared for modelling. |
| `docs/` | Technical documentation, QA/QC workflow, and data governance notes. |
| `leapfrog/` | Leapfrog project notes, screenshots, exports, and modelling assumptions when sanitized. |
| `qgis/` | QGIS project notes, maps, styles, and spatial references when sanitized. |
| `notebooks/` | Optional analysis notebooks or scripts for validation and reporting. |
| `outputs/` | Figures, exports, reports, and final portfolio deliverables. |
| `reports/` | Written technical reports and case study summaries. |

## Current Status

## Confidentiality Standard

Before adding any file, assume it is confidential unless proven otherwise. Public materials should use anonymized names, shifted or removed coordinates, synthetic records, and non-sensitive screenshots.
